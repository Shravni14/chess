# Knight's Gambit

An elegant, feature-rich online chess application crafted by **August**.

## Features

- **Robust Chess Engine**: Full legal move validation, check, checkmate, stalemate, castling, en passant, pawn promotion, fifty-move rule, threefold repetition, and insufficient material.
- **Multiple Game Modes**:
  - Single-player AI with selectable difficulty (Casual, Club, Sharp).
  - Local two-player hot-seat mode.
  - Online multiplayer rooms with join codes.
- **Customizable Board & Pieces**: Selectable themes (Classic Wood, Midnight Obsidian, Emerald Marble, Royal Gold) and distinct piece sets (Glyph, Classic, Modern, 3D-styled).
- **Game Controls**: Move history, undo, resign, draw offers, captured pieces scoring, and database persistence with auto-resume.
